# Bali Reset — лэндинг ретрита

Одностраничный лэндинг ретрита на Бали (7 дней, вилла в Чангу).

## Структура

```
index.html      — сама страница
assets/         — фотографии, используемые на странице
```

## Как опубликовать через GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `bali-retreat`).
2. Загрузите в него содержимое этой папки — `index.html` и папку `assets` целиком, сохраняя структуру.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/root`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<ваш-username>.github.io/bali-retreat/`

## Как загрузить файлы (через веб-интерфейс, без командной строки)

1. На странице репозитория нажмите **Add file → Upload files**.
2. Перетащите `index.html` и всю папку `assets` (можно перетащить папку целиком — GitHub сохранит структуру).
3. Нажмите **Commit changes**.

## Важно

- Не переименовывайте файлы внутри `assets/` и не меняйте структуру папок — `index.html` ссылается на них по относительному пути (`assets/имя-файла`). Если переименуете фото, ссылки в коде тоже нужно будет поправить.
